Game Future

Spell Check Game Development Plans

Gameplay

Spell Check blends turn-based strategy with vocabulary. Each word you spell correctly is converted into a unique magical attack. In a fuller release, these spells would interact with more depth. While the game has some combo words (like fire and wind combining for more damage), it isn't as developed as it could be. We would likely add more combinations, like having ice do less damage if fire was used. Or, dark and light causing major debuffs for an enemy. Each element should interact or stand out in some way.

World Building

The game currently doesn't provide much context for the player. But we do have a story. After the tutorial fight, we would like to add a small cutscene. In it, the player finds a blood path leading to the hidden dungeon. We could also add things within each floor that clues the player into what's going on. The evil teacher is conducting experiments on many fantasy creatures, and in a fuller release we would provide the details of these experiments through NPCs and lore items scattered throughout the dungeon.

Exploration

Right now, the dungeon can feel stagnant and bare. While there're plenty of enemies to fight, there's no pickups or paths that incentivise decision making. As such, we would like to add a currency system and some traps within the dungeons. If there were shops and money laying around, there's an incentive to play risky for greater rewards. However, having traps could also provide risk for exploring without care. As such, these elements would provide the game with more depth for the player.
